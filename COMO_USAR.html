🚀 Como Iniciar o Aplicativo

1 Verificar Requisitos
Certifique-se de que o Node.js está instalado no seu computador.

📥 Baixar Node.js
2 Iniciar o Servidor
Opção A - Automática (Recomendado):
Execute o arquivo INICIAR.bat (Windows) ou INICIAR.sh (Linux/Mac)

Opção B - Manual:
Abra o terminal na pasta do projeto e execute:
npm install
npm run dev
3 Acessar o Aplicativo
Aguarde até aparecer a mensagem:
Local: http://localhost:3000/
Depois, abra o navegador e acesse:

🌐 http://localhost:3000
✅ Primeiro Acesso: Use as credenciais fornecidas pelo administrador do sistema.
⚠️ Importante: Mantenha o terminal aberto enquanto usa o aplicativo. Para parar o servidor, pressione Ctrl+C no terminal.

💾 Backup e Segurança

O sistema armazena todos os dados localmente no navegador com chave de integridade para segurança.


Recomendamos fazer backup regularmente:

  1. Acesse o menu "Importar/Exportar"
  2. Clique em "Gerar Backup"
  3. Salve o arquivo JSON em local seguro
