📋 Como Iniciar o Aplicativo

  1. Abra o terminal ou prompt de comando na pasta do projeto
  2. Execute o comando:
    npm run dev
  3. Aguarde até aparecer a mensagem:
    Local: http://localhost:3000/
  4. Abra o navegador e acesse: http://localhost:3000
✅ Primeiro acesso: Use as credenciais fornecidas pelo administrador do sistema.
⚠️ Importante: Mantenha o terminal aberto enquanto usa o aplicativo. Para parar, pressione Ctrl+C no terminal.
🚀 Abrir Aplicativo
