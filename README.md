## 🚀 Início Rápido

### Método 1: Script Automático (Windows)
```
Clique duas vezes em: INICIAR.bat
```

### Método 2: Script Automático (Linux/Mac)
```bash
chmod +x INICIAR.sh
./INICIAR.sh
```

### Método 3: Python Server
```bash
python iniciar.py
```
Acesse: http://localhost:8080

### Método 4: Desenvolvimento
```bash
npm install
npm run dev
```
Acesse: http://localhost:5173

## 💾 Backup

Os dados são salvos no navegador (localStorage).

**Fazer backup:**
1. Acesse "Importar/Exportar"
2. Clique em "Gerar Backup"
3. Salve o arquivo JSON em local seguro

**Restaurar backup:**
1. Acesse "Importar/Exportar"
2. Clique em "Restaurar Backup"
3. Selecione o arquivo JSON

---

## 📱 Acesso Mobile

1. Inicie o servidor no computador
2. Conecte celular na mesma rede WiFi
3. Acesse: `http://[IP-COMPUTADOR]:8080`

## 🎯 Funcionalidades Principais

- ✅ **Painel Geral do MASTER** - Visão consolidada de todas as igrejas
- ✅ **Gestão de Membros em Lote** - Importação via CSV e salvamento em massa

- ✅ Gestão de Membros e Dizimistas
- ✅ Controle de Lançamentos (Dízimos, Ofertas, Despesas)
- ✅ Sistema de Provisões (Reserva de Emergência)
- ✅ Gestão de Congregações e Pastores
- ✅ Controle de Cultos
- ✅ Remessa Mensal (Modelo Oficial)
- ✅ Fluxo de Caixa
- ✅ Relatórios Detalhados
- ✅ Valores Fixos (Missões, Jubilados)
- ✅ Personalização de Cores
- ✅ Backup e Restauração
